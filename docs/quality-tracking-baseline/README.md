# 独立钉钉质量测试入口基线

## 任务方案状态一致性 r20（2026-09-20）

待规划、方案待确认、待配负责人、待补充、可以发放分别展示。生成方案由非占位任务判断，确认由服务端成果映射确认状态判断；不按任务条数判断完成拆解，一项任务也可确认。标题计数、说明、右侧步骤及配置提示一致，任务结构改变后返回方案待确认。last_verified_at: 2026-09-20


## 草案依赖修复 r19（2026-09-18）

质量初始占位行被规划成完整第一项任务后，转换为 task_1，同时保留后续依赖。仅未确认、无编号冲突且首行交付物和标准完整时转换；空占位、普通任务及其他无效依赖不改。读草稿与修订预校验兼容现存草稿，不批量修改历史。last_verified_at: 2026-09-18


## 草案编辑可读性 r18（2026-09-18）

执行动作与前置依赖为选填，默认收起且保留已有值，通过按钮展开编辑；任务名及长文本自动换行、自适应高度。弹窗和主要列加宽，任务标题使用多行输入，背景独立展开编辑。原提交及业务权限不变。last_verified_at: 2026-09-18


## 主管列表精简 r17（2026-09-18）

未正式分派的事项仅显示主管及状态，不在员工／分配事项列重复展开初析和来源正文。正式任务名称最多两行，每个事件预览两项，其余点击事件查看；完整详情及业务数据保留。last_verified_at: 2026-09-18


## 主管先承接再分配 r16（2026-09-18）

未发放的初析移交先进入“待我承接”，由指定主管确认承接后进入“待分派员工”。旧草稿保留，已发放/关闭事项不补造承接。旧规划链接在承接前转回主管工作台，编辑、AI 规划与发布后端均有门禁。承接记录与真实操作人审计独立追加，不复制正式任务状态。质量总览的时段“终验关闭”指标文案改为“流程完成”，计数口径不变。详见 [r16 记录](../quality-manager-acceptance-20260918.md)。

## 原始研判一致性修复 r15（2026-09-18）

OA 研判明确处理方式与分类的双向配对规则，仅在单一配对冲突时允许模型修正一次，随后仍执行完整校验。其他校验失败与网络错误不自动重试，默认非 OA 调用仍只调用一次。提示区分服务失败与结果校验失败，错误记录不包含密钥、来源正文或模型原文。详见 [r15 修复记录](../quality-assessment-fix-20260918.md)。

## 岗位配置与成果任务映射 r14（2026-09-18）

以本节作为本次改造后的补充基线；下文 r13 及更早记录保留为历史。业务操作使用“客服主管”“质量主管”，实际身份保留在审计。管理员通过 `/admin/posts.html` 配置真实岗位与测试岗位，每岗一人，版本校验防止覆盖他人修改。换人后即时撤销旧岗位权限并接续未完成工作；不改写已有部门任务及历史数据。

初析的必须成果与执行任务分离。新移交只建立待规划占位项，主管可让 AI 生成或手工增删、拆分、合并任务；每项成果须明确一个最终交付任务和可选支撑任务，同一任务可交付多项成果。人工确认结构后才能选人、发放；一项任务也可成立。结构变更使确认失效，日期与人员变更沿用原流程。详见 [r14 实施和验证记录](../quality-roles-planning-20260918.md)。


## 主管移交可见性 r13 修复（2026-09-17）

独立质量试点已发布 r13：最新初析移交给主管但尚未生成正式任务时，主管列表及详情可见，并提供进入原任务分配侧会话的入口。仅接收主管获得该可见性；不新增分派状态、不改通知开关、不迁移数据库。两条受影响事件已在线上投影核验恢复，详见[修复记录](../quality-handoff-fix-20260917.md)。

## 成果与证据生成 r21（2026-09-21）

新 AI 初析要求成果以业务结果和可核验证据为核心，报告可作载体，不机械套报告或结案。历史案例只供调查参考，不预设本次根因；未查明须说明未决项。新增保守校验拒绝明确预设原因、独立审批/终验/关闭门槛及仅交文档的标准；并非完整语义判断，仍须人工复核。已有快照与人工编辑不批量重写。last_verified_at: 2026-09-21


## 方案缺项检查 r22（2026-09-21）

草案接口返回必须成果覆盖缺项，页面显示方案不完整及成果名称。确认不再自动把遗漏成果注入任务；每项成果须在指定最终任务的交付物中保留原名并具备完成标准。确认与发放共用覆盖检查；名称匹配只是可追溯合同，不代替主管核对执行范围和标准。一项任务仍可覆盖多个成果，历史正式任务不改。last_verified_at: 2026-09-21
