last_verified_at: 2026-09-14

用户确认在员工任务卡片里直接完成主管验收。新增页内验收意见和退回表单，直接调用原主管质量验收接口；人员分派、正式状态与任务关联沿用已有权威数据。退回明确显示该员工及具体任务，其他任务不重置，证据和意见保留。修复补交后仍显示上次退回状态的问题。
