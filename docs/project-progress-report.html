四、当前能力与架构

编排
runOrchestrator，默认最多 6 轮工具迭代；输出取最终 end_turn 轮消息。
模型
DashScope OpenAI 兼容接口；QWEN_MODEL 可切换；钉钉侧默认关闭 thinking 以降低首包时延。
工具画像
planner / manager / admin / employee 分级暴露；含检索员工、相似计划、可选联网、事实记忆、发布与管理等。
数据层
任务与子任务落库；subtasks.extra_json v2 支持输入材料、动作、协作人、范围等展示字段。
可观测
orchestrator_done 审计；耗时与 traces；结构化日志可选。
测试
npm test（Vitest），CI 友好默认关闭审计写盘等副作用。
