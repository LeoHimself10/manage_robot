# 佟成质量处理工作台 · 2026-09-08

独立可交互评审件，沿用马荣鑫原型样式，并实际对照 8797 本地原系统的佟成测试身份、质量初析、必须提交成果、责任结构与证据、终验与审计页面。未修改正式前端、API、SQLite 或原型参考文件。

入口：<http://127.0.0.1:8809/>。启动目录为本目录，运行：

```powershell
python -m http.server 8809 --bind 127.0.0.1
```

## FR 与验收标准

- FR-TONG-01：统一员工视角，显示“质量管理能力已开通”；按待初析、跟踪、待终验、退回重开、关闭及全部事件筛选。选中行下全宽展开，始终只展开一个事件；阶段切换不移除流程导航。
- FR-TONG-02：原始来源、AI 原建议、马荣鑫结论、佟成初析分层展示。AI 快照显示来源/规则/案例/模型提示词版本，不使用未经校准的准确率。
- FR-TONG-03：主动生成 AI 初析，原稿与人工草稿分开保存；包含问题方向、主管分类只读引用、来源摘要、已确认事实、分析依据、初步结论、原因假设、待调查方向、信息缺口、处理要求、部门候选、建议期限与必须成果候选。草稿允许不完整保存；正式确认必须选择主责部门、至少一项完整成果并填写确认说明。来源更新需核对；完成版本不覆盖。
- FR-TONG-04：分配后修订保留 V1/V2/V3。任务要求、成果或建议期限变化时标记待主管同步；同步前正式任务投影保持原值。主管确认同步的演示会恢复受影响任务执行及重新验收。
- FR-TONG-05：主管根卡、并行任务折叠卡、任务内证据。查看承接、进度、提交与主管验收。证据归属于具体任务，按版本预览、下载。人员、改派、改期与主管验收不在质量页提供业务编辑入口。
- FR-TONG-06：终验校验四项核对、结论字段、正式任务验收、叶子证据及待同步变更。关闭后只读；退回/重开必须选任务、填原因和补充要求，展示受影响上游链，保留其他任务及全部历史证据和关闭记录。
- FR-TONG-07：补充情况独立留存；通知失败可重新入队。浏览器刷新保留演示进度；支持确认后重置演示状态。
- FR-TONG-08：1366×768、1920×1080 下无页面横向溢出；正文输入 14px，主要输入高度至少 42px，长表单全宽展示。

深链支持 `?record=a8&tab=final`；`tab` 可为 `source`、`assessment`、`analysis`、`tasks`、`evidence`、`final`，以及 `scope` 中文范围。

## 状态、数据与审计

仅浏览器 `localStorage`，键为 `tong-quality-review-20260908-v1`。`events` 保存质量上下文，`formalTasks` 保存单独的正式任务模拟投影。没有业务网络写请求；唯一 `fetch` 用于读取本目录演示日志附件。

质量流程：待初析 → 待主管分配 → 执行/承接/主管验收 → 待质量终验 → 已关闭。终验可退回指定任务；关闭后可重开指定任务。演示重置恢复初始样例。

审计模拟记录：`time/person/title/text`，并在初析版本中保留 `version/author/time/sourceVersion/reason`，退回中保留 `taskId/reason/requirements/time`，终验中保留分类、根因、措施、验证、结论、终验人及时间。通知重试另有公开动态。实际服务端事务、幂等、权限和并发并未在本次原型中迁移或上线。

证据包为可读 TXT 导出，包含任务说明及全部历史证据版本；不是正式系统中的 ZIP 归档接口。

新增交互入口：<http://127.0.0.1:8809/?record=a4&tab=analysis>。

1. 打开或刷新不会自动调用生成；用户点击后展示生成中、成功或失败状态。
