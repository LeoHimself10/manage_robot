周度 Dashboard · 本地部署与手动验收

本文档对应四阶段增量计划（Workbench 接线 → UI 对齐 → 周会 UX → 逻辑/Portfolio）。 本地服务使用 npm run dev:manager-chat，已预置演示正式任务与 Portfolio 数据。

● 服务地址 http://127.0.0.1:8787

一、本地部署（已完成可跳过）

若端口被占用，先停止旧进程再启动：
Get-NetTCPConnection -LocalPort 8787 | % { Stop-Process -Id $_.OwningProcess -Force }
然后：cd D:\manage_robot → npm run dev:manager-chat
  1. 确认 Node ≥ 22；可选在 .env 配置 QWEN_API_KEY（周会建议 LLM；无 key 时走规则模板）。
  2. 启动后终端应打印「5) 周度 Dashboard」链接；健康检查：/health 返回 ok。
  3. 数据目录：data/local-manager-chat-dev/（本次为全新重置 seed）。
  4. 测试账号：userId = manager-local-dev（测试登录页选「自动判定」或「主管」）。
1. 登录页 http://127.0.0.1:8787/workbench 2. 周度 Dashboard（主验收页） http://127.0.0.1:8787/workbench/manager/dashboard 3. 项目总览（Portfolio 深链） http://127.0.0.1:8787/workbench/manager/projects 4. 历史任务（对照 UI） http://127.0.0.1:8787/workbench/manager/tasks

三、阶段验收清单

在浏览器打开 Dashboard 后逐项勾选。全部通过即四阶段验收完成。

P1Workbench 接线

  • 导航可进入，不再 404
    顶栏「周度 Dashboard」高亮；页面标题「周度 Dashboard · 主管工作台」
  • 首屏数据加载成功
    rangeMeta 非「加载失败」；6 个 KPI 有数字；甘特区非空（有截止日的子任务）
  • 退出 / 视图切换
    「退出」回到登录页；「我负责的任务」可切换员工视图（或提示无员工身份）
  • weekInput 与 API 同步
    加载成功后日期框 = 当前中心周周一（YYYY-MM-DD）

P2UI 对齐工作台

  • 周导航 + 自动刷新
    ‹ ›、上周/本周/下周 chip 可切换；改 span 或日期后自动刷新（无需仅点刷新）
  • 6 KPI + 语义色
    含「本周动态」格；完成=绿、待承接=橙、阻塞/逾期=红
  • 历史周黄条
    切到明显过去周（如 2026-01-05）出现黄色 info-banner「历史状态近似…」
  • Tabs / 表格 / Badge / 时间
    明细 Tab 为工作台 .tabs-btn；子任务表 table.data；状态中文 badge；动态时间为 yyyy-MM-dd HH:mm
  • 任务折叠 + 中文动态
    <details> 默认折叠；summary 有 attention badge；feed 显示 actionLabel 非 SUBTASK_* 英文

P3周会 UX

  • 人员 Tab → 卡片（非 day 网格）
    每人一张卡：执行中/阻塞/span到期/下周 四计数；due 小圆 chip；子任务短列表 + 状态 badge
  • 甘特色点 + 图例 + 中心周列
    格内仅色点（hover 有 tooltip）；底部图例；中心周列浅蓝底；周末列略淡
  • 周会建议助手 UI
    初始虚线占位；点击「生成本周建议」后出现分区；左侧色条区分优先级；无 API key 时显示「已使用规则模板」

P4逻辑 + Portfolio

  • KPI 不自相矛盾
    同一子任务不会同时计入「本周完成」与「待承接/执行中/阻塞」；演示数据中完成事件不与活跃 KPI 双计
  • 动态 feed 加载更多不闪屏
    点「加载更多」仅追加 feed，甘特/明细/人员区不重绘闪动（Network 可见 feedOnly=1）
  • 项目筛选（Portfolio）
    顶栏有「项目筛选」下拉（全部 / 未归类 / 各项目）；选「Q2 渠道复盘」后 KPI/任务范围缩小
  • 项目总览 → Dashboard 深链
    项目卡片有「周度 Dashboard」按钮，URL 带 ?projectId=proj:... 且筛选预选

四、API 冒烟（可选，开发者）

登录后从浏览器 DevTools → Application → Cookies 复制 session，或使用测试登录后的同一浏览器会话。

请求预期
GET /api/workbench/manager/weekly-dashboard?week=2026-05-20&span=1 { ok:true, kpi, timeline, tasks, feed, week.mondayYmd }
GET ...&feedOnly=1&feedCursor=offset:0 仅 feed + 轻量 kpi.eventCount，无 tasks/timeline
POST /api/workbench/manager/weekly-advisor body { week, span } { ok:true, sections:[], renderSource }
GET ...&projectId=proj:...（Portfolio 用户） 任务列表仅含该项目；非 Portfolio 用户忽略 projectId
