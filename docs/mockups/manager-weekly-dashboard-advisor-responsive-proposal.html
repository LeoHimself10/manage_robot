推荐 · 按需抽屉（Drawer on demand）

最佳实践：甘特是主信息区，必须优先保证全宽 + 横向滚动。 周会助手是按需触发的辅助面板，窄屏不应常驻占列。

规则： ≥1280px → 右侧 sticky 侧栏（与现网一致）； <1280px → 时间轴全宽，「周会助手」变为 section 内按钮，点击打开右侧 Drawer（或 Bottom Sheet ≤640px）。 抽屉打开时甘特仍可见、可滚动，不被遮挡。

断点与行为对照

视口时间轴周会助手理由
≥ 1280px 主栏 1fr，横向滚动 右侧 sticky 卡片 280–300px（现网） 宽屏有足够空间，侧栏不抢甘特可视区
960 – 1279px 独占全宽 时间轴标题旁「周会助手」按钮 → 右侧 Drawer 避免双列挤压；助手按需打开，不常驻占宽
< 640px 全宽 + 更紧凑 KPI 同上，Drawer 可改为 Bottom Sheet 移动端拇指区友好；投屏场景仍以桌面为主

为何不用「直接堆叠到下方」

方案优点缺点
窄屏侧栏移到甘特下方（现网 1080px 单列） 实现简单 投屏过会时要滚很远才到助手；中间宽度仍重叠
Modal 居中弹窗 完全不挡甘特 遮挡整屏，不适合边看过会边对照时间轴
Drawer 按需（推荐） 甘特始终全宽；助手与甘特可同屏对照；符合 Ant Design / Material 侧栏模式 需增加开关状态与 Esc 关闭（工作量小）
