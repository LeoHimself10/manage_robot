周度 Dashboard · 增量修改计划

在专家已有代码（weekly-dashboard/* + manager-dashboard-page.ts）基础上修补与对齐，不重写领域层。 下面分阶段说明改什么、改完你能看到什么；最下方是改完后的页面长什么样（示意）。

保留：facts / timeline / advisor 核心逻辑 修补：接线 / UI 对齐 / KPI 一致性 不做：整页重做 / 钉钉机器人 / 导出

阶段 1 · 能打开、能加载（约 1–2 天）

  • 接线 workbench：在 assignment-workbench.ts 注册 /workbench/manager/dashboard、 GET /api/workbench/manager/weekly-dashboard、 POST /api/workbench/manager/weekly-advisor
      点击导航不再 404；页面能拉到真实 KPI / 甘特 / 动态
  • 接通讯录姓名：API 里给 facts 传 resolveName（同进展推送）
      负责人列显示「张三」而不是 userId 字符串
  • 补页面基础 wiring：退出登录、员工视图切换（与历史任务页一致）
      右上角按钮都能用，不会点了没反应
  • 周控件同步：加载后把 API 返回的周一日期写回日期控件
      打开页面日期与「2026-W21 · 5/19–5/25」一致，不会空白

现在

点「周度 Dashboard」→ 404 或 API 失败

阶段 1 后

能进页、能看真实数据、负责人有姓名

阶段 2 · 用起来像工作台（约 2–3 天）

  • 时间栏：加「‹ 上周 · 本周 · 下周 ›」和快捷 chip；切换后自动刷新（可保留刷新按钮作重试）
      开会不用再选日期 + 点刷新；一切就能讲「本周」
  • KPI 第 6 格：单独展示「本周动态」；阻塞/逾期/完成用红/绿语义色
      一眼看到要盯的数字；和 v2 规格一致
  • 历史周提示条：approxHistoricalState 时顶部黄条
      看上周数据时知道「颜色是近似值」，不会误解
  • 复用工作台组件：状态改中文 badge（执行中/阻塞中/已完成）；表格用 table.data；Tab 用 .tabs + 无障碍属性
      和历史任务、项目总览同一套视觉，不再像 demo 页
  • 任务明细：accordion 默认折叠；只展开要讲的任务
      10 条任务不会一屏全是展开的表
  • Feed：事件类型显示中文标签（进度更新/阻塞/完成），不是 SUBTASK_PROGRESS
      动态列表适合投屏朗读

阶段 3 · 人员视图 + 甘特可读（约 2 天）

  • 人员 Tab 改版（重点）：去掉第二套「人员 day 网格甘特」；改为人员卡片：头像区 + 执行中/阻塞/span内due/下周due 四计数 + 子任务短列表
      按人过周会时：「李四 1 阻塞、2 执行中」+ 点开的子任务名，不再是一排看不懂的小格
  • 任务甘特微调：格子里只显示色点（或 1–2 字），完整标题在 hover；加中心周列高亮 + 图例
      甘特能扫读，不会 34px 格里挤一长串字
  • 建议助手：首次未生成时虚线占位；必谈/关注分块左边框颜色；超时提示更明显
      侧栏更像「周会提纲」，不是空白一块

现在 · 人员 Tab

又一张 day 表格，和任务甘特重复

阶段 3 后

人员卡片 + 子任务列表，专门用来「逐人问进展」

阶段 4 · 逻辑修补 + 项目联动（约 1–2 天，可后置）

  • KPI 一致性：本周已完成（事件）的子任务，不再同时计入「待承接」
      KPI 数字不再自相矛盾
  • Feed 过滤：动态列表只用业务相关 event 类型（进度/接受/阻塞等）
      动态区干净，没有通知类噪音
  • 加载更多：只追加 feed，不重建甘特/明细
      点「加载更多」页面不会闪一下重绘
  • Portfolio（可选）：顶栏项目下拉 + ?projectId= 筛选；项目总览卡片加「本周进展」链到 Dashboard
      多项目主管：先选「注册申报」再看该专项本周情况
  • 测试：assignment-workbench API 集成测试 + KPI 边界用例
      发版有信心，不会再次「页面对了 API 没注册」
