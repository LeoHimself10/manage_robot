P0-2成功反馈太弱

P0-3改完去哪登录

P0-4账号信息闪「—」

P1-5层级重复

页标题 + 描述 + 账号条 + 蓝条 + 卡片 h2，信息堆叠。

P1-6文案偏内部

P1-7表单体验不足

无显示/隐藏密码；当前密码错时不标红字段；规则不全。

P1-8和其他 Tab 风格分裂

P2-9导航 Tab 过多

5 个 Tab 在小屏等分，扫读困难。

P2-10Tab 晚出现

「账号安全」等接口返回才显示，书签直达时会闪一下。

修改计划（三阶段）

按投入从小到大；推荐至少做阶段 1 + 2。

阶段 1 · 信任与反馈 优先

约 0.5 天 · 解决「像 bug / 像没改成功」
  1. 错误中文化：服务端 + 前端统一 →「当前密码不正确」等
  2. 成功 banner：表单上方绿色条「密码已更新，下次请用新密码登录」
  3. 账号条 loading：接口返回前显示骨架，禁止长期「—」
  4. 补登录链接：提示条加 /workbench/external/login 可点击
验收：错密码 → 中文红字、不跳页；成功 → 明显绿条；无「—」闪烁。

阶段 2 · 表单与层次 推荐

约 0.5～1 天 · 达到常见「账号安全」页水准
  1. 精简层级：去掉重复标题/描述，保留「账号摘要 + 一条提示 + 表单」
  2. 密码框增强：显示/隐藏；当前密码错时字段标红
  3. 规则补全：新密码不能与当前相同；实时 ✓/○
  4. 提交态：按钮「提交中…」+ aria-busy；可选二次确认
  5. 表单限宽：max-width ~480px，宽屏不散
  6. 文案用户化：「登录名 wuchuanbin · 账号密码登录」
验收：手机可核对密码；错误能定位到字段；视觉不空、不挤。

阶段 3 · 导航与统一 可选

约 0.5 天 · 需你选 9A 或 9B（见下）
  1. 导航收纳：9A 合并「我的」或 9B 小屏滚动/更多
  2. Tab 预渲染：避免外部 Tab 突然出现
  3. 样式统一：提示条与任务 Tab 同一套 info-banner
  4. 无障碍：aria-describedby、错误后 focus 到字段
