任务规划机器人 · 主管使用指南

适用于任务主管 / 项目经理 · 2026-05

能帮您做什么

  • 规划：把目标拆成可执行的子任务（交付物、完成标准、截止、依赖等）
  • 发布：指定负责人，确认后正式派发给员工
  • 跟踪：在工作台查看进度，处理员工拒绝、修改申请、阻塞等
  • 干预：改派、手动催办、驳回员工申请
  • 查询：问机器人「我管理的任务有哪些逾期」等
  • 日报：工作日推送任务概览（需您处理 / 正常推进 / 昨日动态）

当前不做 OA 审批、电子签名、验收闭环；仅维护协作层任务状态。钉钉通知、日报、自动催办需公司已部署并开启。

工作台 · 任务列表

打开「历史任务」，顶部数字和列表上的关注状态帮助您优先处理：

待您处理 员工拒绝，或申请修改等您回复
待员工承接 已发布，员工尚未接受
员工执行中 有子任务在执行
阻塞中 有子任务被员工标记阻塞
已完成 全部子任务已完成

列表可按关注状态、标题、负责人筛选排序。「调整分配」Tab 支持整单或单条子任务改派。

改派后新员工会收到通知；未完成子任务状态回到「待承接」。

员工侧（帮您理解通知）

  1. 发布后：员工收到工作通知和机器人消息（含工作台链接）
  2. 员工在工作台「待承接」点接受 → 子任务变为执行中
  3. 钉钉待办在员工接受后才创建——发布当下待办里没有，属正常
  4. 拒绝 / 申请修改 → 钉钉通知您，列表进「待您处理」
  5. 阻塞 → 钉钉通知您，列表优先显示「阻塞中」
  6. 完成 → 钉钉通知您，可点「已知悉」；不会进「待您处理」

自动提醒（公司开启后）

  • 进展日报：工作日约 9:00，推送需您处理、正常推进、昨日动态
  • 截止前提醒：截止前一日约 10:00 提醒员工（工作日）
  • 逾期提醒：子任务逾期后，系统通知您（同一逾期周期一次）

您在工作台或钉钉里手动「催办」只推送给员工，可随时操作，不占自动提醒次数。手动催办适用于执行中 / 阻塞且有截止日期的子任务。

批量分配（可选）

一次派给多人时，可在「智能规划助手」上传花名册（md / txt / docx / pdf），上传后在对话框说明分配意图。须已有规划会话（通常先在钉钉发第一条消息）。

也可在钉钉直接说负责人姓名；系统会先查通讯录再写入分配方案。

常见问题

机器人一直追问、不出任务表？

通常缺截止日期或目标不清楚。请补充：什么时候要、怎样算完成、涉及哪些人。

说了「确认发布」，员工没收到？

请确认已看到发布预览后再说「确认发布」。到工作台「历史任务」核对是否已有该任务。若仍不行，可在「智能规划助手」重试，或联系管理员。

新任务必须从钉钉开始吗？

建议先在钉钉机器人发第一条消息（系统据此建立规划会话）。之后可在工作台「智能规划助手」续聊、上传花名册或完成发布。

进了员工界面，或钉钉只能查本人任务？

说明当前账号不在主管名单，走的是员工助手。请联系管理员加入主管名单后，重新打开工作台或再发钉钉消息。

日报、自动催办和手动催办有什么区别？

日报：每天任务全景。自动催办：截止前提醒员工、逾期后提醒主管（公司开启后）。手动催办：您主动对某条执行中 / 阻塞子任务发起，只通知员工。
