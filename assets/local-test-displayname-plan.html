displayName 修复 · 本地测试方案

前提：.env 已存在且 QWEN_API_KEY 已配置（你当前环境已满足）。Node ≥ 22。

层级 1 · 秒级（无 LLM）

验证 prepare 后 assignment 与结构化表是否显示姓名。

cd d:\manage_robot
npm run test:displayname-local

期望：输出「全部通过」。

层级 2 · Agent eval（约 20s，需 API）

与 ECS 曹杰场景一致：点将 → prepare → 表断言。

$env:EVAL_AGENT_FILTER="M_micro_assign_prepare"
$env:EVAL_DATA_DIR="d:\manage_robot\.eval-agent-displayname"
npm run eval:agent

期望：M_micro_assign_prepare: OK，进程 exit 0。

层级 3 · 浏览器手工（最接近钉钉）

预置微导管草案 + 通讯录「李嘉男」，在工作台对话里走完整 Agent。

npm run dev:microcatheter-repro
  1. 打开 http://127.0.0.1:8787/workbench
  2. 测试登录 → userId: manager-local-dev → 主管
  3. 进入智能助手（主线程）
  4. 发送：请把当前草案全部子任务点将给李嘉男，并做发布预览，不要发布。
  5. 看回复中「结构化任务表」→ 负责人列应为 李嘉男，不能是 02573051084320
